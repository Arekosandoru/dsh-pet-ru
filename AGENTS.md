# AGENTS.md — инструкция для AI-агента

Ты помогаешь пользователю поставить русский перевод плагина **dsh-pet** в DeepSeek Harness.
Это оверлей: готовые переведённые файлы + скрипт, который кладёт их поверх установленного
оригинального плагина. Задача — выполнить шаги ниже и ничего не изобретать.

## Что нужно знать заранее

- Совместимо только с **dsh-pet 0.3.8**. Версия проверяется автоматически по sha256.
- Плагин ищется в `~/.dsh/profiles/*/node_modules/dsh-pet` (Windows: `%USERPROFILE%\.dsh\profiles\...`).
- Перезаписываются 11 файлов, 133 ассета переименовываются. Скрипт делает бэкап.
- Установщик идемпотентен: повторный запуск ничего не ломает.

## Порядок действий

1. Убедись, что dsh-pet установлен: найди папку плагина
   (`~/.dsh/profiles/*/node_modules/dsh-pet` или её сообщил пользователь).

2. Покажи план и спроси подтверждение, если пользователь не просил ставить сразу:

   ```bash
   node install.mjs --dry-run
   ```

   Ожидаемый вывод: `План: скопировать 11 файлов, переименовать 133 ассетов.`
   Если скрипт говорит про другую версию — **остановись**, см. «Когда остановиться».

3. Установи:

   ```bash
   node install.mjs
   ```

   Если профилей несколько, скрипт попросит `--dir <путь>`; возьми тот, что указал пользователь.

4. Проверь результат — скрипт сам сверяет хеши и пишет `Готово.`. Дополнительно убедись,
   что в папке плагина появились русские имена, например:

   ```bash
   ls ~/.dsh/profiles/*/node_modules/dsh-pet/assets/webm | head -3
   ```

5. Скажи пользователю перезапустить DSH; для веб-интерфейса достаточно обновить страницу
   (`Ctrl+R`). Без перезапуска часть строк (хост-половина) останется прежней.

6. Отчитайся: путь к папке плагина, число файлов, путь бэкапа, что перезапуск нужен.

## Когда остановиться и спросить

Не продолжай, если:

- установлен не 0.3.8 — перевод надо обновить, файлы не трогай;
- файлы плагина уже кем-то правились (хеши не совпадают) — установщик сам откажется;
- папка плагина не найдена или профилей несколько и пользователь не выбрал;
- пользователь не подтвердил установку.

## Откат

```bash
node install.mjs --restore "<путь из вывода установщика>"
```

## Чего не делать

- Не редактируй файлы плагина вручную и не копируй `files/` по одному: скрипт делает
  бэкап, проверку версии и переименования, руками это разойдётся с `manifest.json`.
- Не обновляй dsh-pet в процессе. Не удаляй бэкап.
- Не трогай пользовательские настройки в `~/.dsh/dsh-pet/` (`main-config.jsonc`, `memory.json`).
