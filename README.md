# dsh-pet-ru

Неофициальный русский перевод плагина [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) для DeepSeek Harness.
Не форк: репозиторий содержит только переведённые файлы и установщик, который кладёт их
поверх уже установленного оригинального плагина.

## Совместимость

Только с **dsh-pet 0.3.8**. Установщик сверяет sha256 каждого файла и на другой версии
откажется что-либо менять — так новые функции апстрима не затираются.

## Как поставить

Человеку:

```bash
node install.mjs
```

Агенту — дайте ссылку на этот репозиторий; он прочитает [AGENTS.md](AGENTS.md) и сделает то же самое.

Установщик сам находит плагин в `~/.dsh/profiles/*/node_modules/dsh-pet`, делает бэкап,
копирует 35 файлов (11 текстовых + 24 перерисованных мема) и переименовывает 133 ассета.
После этого перезапустите DSH (в браузере достаточно обновить страницу).

Если профилей несколько: `node install.mjs --dir <путь к папке dsh-pet>`.
Только посмотреть план: `--dry-run`.

## Что меняется

- `lib/client.js`, `lib/index.js`, `lib/standalone.js` — интерфейс, меню, настройки, уведомления, CLI.
- `assets/config.jsonc` — имена анимаций, тексты статусов, промпты.
- `runtime/electron-helper/*.js` — окно питомца в режиме рабочего стола.
- `package.json` — описание в менеджере плагинов.
- `assets/memes/*.png` — 24 мема перерисованы: китайские подписи закрашены, русский текст
  нарисован шрифтом самого плагина (в нём есть кириллица).
- 133 ассета (106 видео, 26 мемов, шрифт) переименовываются: имя файла анимации обязано
  совпадать с её именем в конфиге, поэтому без этого русские названия не заработают.

Содержимое видео не меняется — только имена.

## Откат

Установщик печатает путь бэкапа. Вернуть как было:

```bash
node install.mjs --restore "~/.dsh/dsh-pet-ru-backup/<дата>"
```

## Обновление плагина

Обновление dsh-pet затирает перевод. После каждого обновления:

1. Дождитесь новой версии этого репозитория (см. `manifest.json`).
2. Запустите `node install.mjs` снова.

## Сборка под новую версию (для мейнтейнера)

1. Скачайте tarball новой версии с npm и распакуйте — нужна папка `package/`.
2. Перенесите перевод на новую версию:

   ```bash
   python tools/update.py --prev-upstream scratch/upstream-0.3.8/package \
       --prev-ru scratch/ru2-0.3.8 \
       --new-upstream <новая>/package --out scratch/ru-0.3.9
   ```

3. Переведите остатки из `update-report.json` прямо в `scratch/ru-0.3.9`.
4. Пересоберите оверлей и манифест:

   ```bash
   python tools/build.py --upstream <новая>/package --ru scratch/ru-0.3.9 --version 0.3.9
   ```

5. Проверьте установку на копии распакованного пакета:

   ```bash
   node install.mjs --dir <копия>/package --dry-run
   ```

Если в новой версии появились ассеты, `build.py` перечислит их — их надо перевести
и дописать в `renames.json` (иначе русские названия анимаций не заработают).

## Ограничения

- Комментарии внутри `assets/config.jsonc` остаются на китайском: это документация к файлу
  настроек, на работу интерфейса не влияет.
- Строки, добавленные в dsh-pet после 0.3.8, останутся китайскими, пока репозиторий не обновят.
- В двух анимациях с репликами («Размышляет», «Что поесть») и на карточке 福 текст пока
  китайский: видео — следующий этап.
- Файлы плагина заменяются целиком, поэтому перевод надо переустанавливать после апдейта.
